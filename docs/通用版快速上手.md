# 万能创作终端 · 通用版快速上手（1 页）

> 适合：使用任意 new-api / OpenAI 兼容站点的用户。详细说明见 [通用版使用手册](通用版使用手册.md)。

## 第 1 步：下载安装

1. 打开 GitHub 发布页 <https://github.com/ginsonko/omnicreator/releases>（或官网下载区）。
2. 选文件：
   - Windows：`…-Setup.exe`（安装版，推荐）或 `…-Portable.exe`（免安装版）
   - Mac Apple 芯片：`…-mac-arm64.dmg`；Mac Intel：`…-mac-x64.dmg`
3. 安装：
   - Windows：双击安装。被拦住时点「更多信息」→「仍要运行」。
   - Mac：把图标拖进「应用程序」，第一次**右键 →「打开」→「打开」**。提示“已损坏”就在「终端」运行：
     ```
     xattr -dr com.apple.quarantine "/Applications/万能创作终端.app"
     ```

## 第 2 步：在 API 站点准备 Key

1. 在站点注册、充值。
2. 进入「令牌 / API Key」页，点「添加令牌」，建三个：`创作终端-文本`、`创作终端-图片`、`创作终端-视频`（建议给每个设额度上限）。一个 Key 能用所有模型时，也可以只建一个。
3. 复制每个 Key（`sk-` 开头），记下接口地址：`https://你的站点域名/v1`。

## 第 3 步：在软件里连接

1. 打开软件 → **设置 → 连接配置 → 手动添加**。
2. 填 **名称**、**接口地址**。
3. 在 **文本**、**图片**、**视频** 三处分别填 Key，并从下拉列表选模型。
4. 点 **保存** → **检查连接**，看到“连接正常”就好了。

## 第 4 步：开始创作

回到首页，在输入框里说（可以直接复制）：

- 写文案：`给新品焦糖拿铁写 3 条小红书文案，每条不超过 80 字`
- 生成图片：`帮我做一张新品咖啡海报，暖色调，留出标题位置`
- 生成视频：`把这张图做成 5 秒视频，镜头缓慢推近`
- 做项目：`做一个三格小漫剧：主角是一只想当程序员的橘猫，先给我分镜`

成果自动保存在右侧「作品」里。

## 记住这几个键

`F1` 帮助 · `F2` 换界面（新手推荐「口袋」） · `Ctrl+K` 搜索一切 · `Ctrl+N` 新对话（Mac 用 `⌘`）

## 其他

- 花费上限：**设置 → 账本与上限**（单个对话 / 每天 / 每月）。
- 更新：有新版会提示「一键更新」，**从不强制**。
- 卸载：Windows「设置 → 应用」或软件「设置 → 关于 → 卸载」；免安装版先「清理数据」再删 exe；Mac 拖进废纸篓。
