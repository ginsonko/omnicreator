# 网站截图与视频待办

通用版去品牌的构建完成之前，网站只用了不含任何旧品牌字样的图片。下面是发布前需要替换或补充的素材。替换后运行 `node scripts/check-site.mjs`，确认没有违禁字样、所有图片都能加载。

## 建议补充的截图（通用版构建完成后）

截图要求：通用版、深色或浅色均可、窗口 1280×792 左右，**画面中不能出现旧品牌名、真实 Key、本机用户名或私人路径**。导出 WebP（质量 80）放进 `site/assets/img/`。

1. `shot-chat.webp`：对话页，用户说“帮我做一张新品咖啡海报”，助手完成并展示作品。用于「能做什么 → 对话做项目」。
2. `shot-manual-add.webp`：设置 → 连接配置 → 手动添加，填好了接口地址（示例域名）和文本 / 图片 / 视频三处模型（Key 打码）。用于「连接站点 → A」以及通用版手册。
3. `shot-import.webp`：一键导入确认窗口（来源显示示例站点）。用于「连接站点 → B」以及接入手册。
4. `shot-workbench.webp`：创作台首页或页面菜单。
5. `shot-faces.webp`：千面界面选择（可拼一张多界面拼图，包括口袋、磁贴、桌面）。
6. `shot-update.webp`：更新提示弹窗（“一键更新 / 以后再说”）。
7. `shot-about.webp`：设置 → 关于（卸载、清理数据按钮）。

替换方法：把新图片放进 `site/assets/img/`，在 `index.html` 里把对应位置的 `<img src>` 改过去（记得写 `width`、`height`、`alt` 和 `loading="lazy"`）。

## 教程视频（在 `config.json` 的 `videos` 里填）

| id | 标题 | 需要填写 |
| --- | --- | --- |
| `general` | 通用版入门 | `url`（视频页面链接或 mp4 地址）、可选 `embed`（播放器嵌入地址）、`duration` |
| `smart` | 第三方智能路由站点接入 | 同上 |
| `promo` | 宣传片 | 同上 |

- 只填 `url` 且是视频网站页面：点击后在新窗口打开。
- `url` 是 `.mp4` / `.webm`：在页面弹窗里直接播放。
- 填了 `embed`：在页面弹窗里用嵌入播放器播放。
- 都留空：卡片显示「即将上线」。

## 手册中的截图占位

`docs/` 下的手册用「【截图占位：……】」标出了需要截图的位置，通用版构建完成后按描述截图，放到 `docs/images/` 并把占位行换成图片链接。
