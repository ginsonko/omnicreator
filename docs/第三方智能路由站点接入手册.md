## 1. 智能路由和一键导入是什么

- **智能 Key（智能路由）**：普通 Key 需要你自己挑模型；智能 Key 会**自动挑选当前可用、合适的模型线路**。比如你说“画一张图”，它会自动走一个可用的图片模型；某条线路暂时不可用时，会换一条。
- **一键导入**：在站点的令牌页点一下，就能把 **接口地址、Key，以及文本、图片、视频和编程助手（Codex / Claude Code）的默认模型** 一次性带进软件，不用手动填写。

两者结合：**注册 → 充值 → 建一个智能 Key → 点一键导入 → 开始创作**。

## 2. 下载与安装软件

1. 打开官网下载区，或 GitHub 发布页 <https://github.com/ginsonko/omnicreator/releases>。如果你的站点提供了下载页或镜像，也可以从那里下载。
2. 按电脑选择文件：
   - Windows 10 / 11：**安装版**（推荐，「一键导入」可以直接唤起软件）或免安装版。
   - Mac Apple 芯片（M1 / M2 / M3 / M4…）：`…-mac-arm64.dmg`
   - Mac Intel：`…-mac-x64.dmg`
3. 安装：
   - **Windows**：双击安装，出现「Windows 已保护你的电脑」时点「更多信息」→「仍要运行」，一路「下一步」。
   - **Mac**：把图标拖进「应用程序」。第一次打开时**右键 →「打开」→「打开」**。如果提示“已损坏”，打开「终端」运行：
     ```
     xattr -dr com.apple.quarantine "/Applications/万能创作终端.app"
     ```
4. 打开一次软件，跟着新手导览走完。**保持软件开着**，接下来导入会更顺利。

> 想核对文件是否完整：官网下载卡片上有 SHA256 校验值。Windows 用 `Get-FileHash 文件名`，Mac 用 `shasum -a 256 文件名`，结果一致即可。

## 3. 在站点注册并充值

1. 打开你所用的站点，点「注册」，按提示完成注册（可能需要邮箱验证）。
2. 登录后进入「钱包」或「充值」页面。
3. 按站点的说明充值，常见方式有：
   - 在线支付；
   - 输入兑换码（活动或客服发放）。
4. 充值后，在控制台首页或钱包页确认余额已到账。

> 建议先少量充值，熟悉费用后再按需补充。

## 4. 创建智能 Key

1. 进入站点控制台的「令牌」（或「API Key」「密钥」）页面。
2. 点「添加令牌」或「创建 Key」。
3. 填写：
   - **名称**：例如 `万能创作终端`。
   - **类型 / 模式**：选择 **智能**（有的站点叫“智能路由”“自动选择模型”“Smart”）。
   - **额度**：建议设一个上限，例如 20 元，避免意外多花。
   - **过期时间**：按习惯选择。
4. 点「提交」。新的智能 Key 会出现在令牌列表里。

> 站点没有“智能”选项？说明它可能不支持智能路由。你仍然可以按 [通用版使用手册](通用版使用手册.md) 手动配置。

## 5. 一键导入到软件

### 5.1 正常流程

1. 在令牌列表里，找到刚建的智能 Key，点这一行的 **「一键导入」**。
2. 在弹窗里选择目标软件 **「万能创作终端」**。
3. 勾选要导入的内容（通常默认全选）：文本、图片、视频、编程助手。
4. 点 **「导入到软件」**。
5. 浏览器会询问“是否打开万能创作终端”，选 **「打开」**（可以勾选“始终允许”）。
6. 软件会弹出 **导入确认窗口**，显示来源站点、Key 末尾几位、各类默认模型。**核对无误后点「导入」**。

> 在你点「导入」之前，软件**不会改动任何设置**。

### 5.2 点了没反应？用这两个备用办法

常见于使用免安装版、浏览器拦截了唤起，或软件没打开。

**办法一：复制导入码**

1. 在站点的一键导入弹窗里点 **「复制导入码」**。
2. 回到软件，**在任何地方按 `Ctrl + V`**（Mac 上 `⌘ + V`）；或在首页、**设置 → 连接配置** 里点「从剪贴板导入」。
3. 在确认窗口里点「导入」。

> 软件开着的时候复制导入码，通常会自动弹出导入提示。

**办法二：下载导入文件**

1. 在站点的一键导入弹窗里点 **「下载导入文件」**。
2. Windows 安装版可以直接双击这个文件；其他情况在软件 **设置 → 连接配置** 点「打开导入文件」选择它。
3. 在确认窗口里点「导入」。

> 导入链接 / 导入码通常 **10 分钟内有效，只能用一次**。过期了回站点再点一次「一键导入」即可。

### 5.3 导错了怎么办

到 **设置 → 连接配置**，在底部点 **「撤销上次导入」**，就会恢复到导入之前的样子。

## 6. 检查是否导入成功

1. 打开 **设置 → 连接配置**。
2. 应该能看到一张新的连接卡片：
   - 显示站点名称、Key 末尾几位，并标有 **「一键导入」** 和 **「智能路由」**；
   - 卡片下方列出 文本 / 看图 / 生图 / 视频 / Codex 模型 / Claude 模型 的默认值；
   - 左侧圆点为“当前使用”。
3. 点 **「检查连接」**，看到“连接正常，可用模型 N 个”即成功。
4. 导入后软件会自动把文本、图片、视频模型同步到创作台（只读取模型列表，不花钱）。如需手动同步，点「同步到创作台」。

## 7. 开始创作

回到首页，在输入框里直接说。下面的话都可以复制使用：

| 想做什么 | 这样说 |
| --- | --- |
| 写文案 | `给新品焦糖拿铁写 3 条小红书文案，每条不超过 80 字，语气轻松` |
| 生成图片 | `帮我做一张新品咖啡海报，暖色调，竖版，顶部留出标题位置` |
| 生成视频 | `把这张图做成 5 秒视频，镜头缓慢推近，保留原图风格` |
| 做漫剧 | `做一个三格小漫剧：主角是一只想当程序员的橘猫。先给我分镜，再逐格出图` |
| 做项目 | `我要给咖啡店做开业宣传：1 张主海报、3 张配图、1 条 15 秒短视频和一段文案。先给我方案` |

说明：

- 使用智能 Key 时，默认走 **「智能绘图 / 智能视频」**，站点自动挑选可用线路。想用某个具体模型，直接在话里点名，例如“用 某某模型 画”。
- 如果站点上这个 Key 的智能视频暂时没有可用线路，助手会告诉你原因，你点名一个视频模型再试即可。
- 图片通常 1 到 2 分钟，视频一般几分钟，成果自动保存在右侧「作品」。

更多功能（Codex / Claude Code 对话、创作台、工作室、项目档案、换皮肤、花费上限）的用法，见 [通用版使用手册 · 功能导览](通用版使用手册.md#7-功能导览附例子)。

## 8. 更新、卸载与常见问题

### 更新

软件会在后台检查新版本，有新版时提示 **「一键更新」**；**从不强制更新**，可以点「以后再说」或在设置里关闭自动检查。更新不影响作品、对话和连接配置。

### 卸载

- **Windows 安装版**：Windows「设置 → 应用」卸载，或软件 **设置 → 关于 → 卸载**。想连设置和 Key 一起删掉，先点 **设置 → 关于 → 清理数据**。
- **免安装版**：软件里 **设置 → 关于 → 清理数据**，然后删除 exe。
- **Mac**：退出软件，把它从「应用程序」拖到废纸篓；彻底清理再删除 `~/Library/Application Support/万能创作终端` 和 `~/Library/Logs/万能创作终端`。

卸载不会删除你自己的作品文件夹。

### 常见问题

**Q：一键导入后，还需要自己选模型吗？**
A：不需要。智能 Key 会自动挑选；想指定模型时，在对话里点名，或在输入框下方的模型菜单里选。

**Q：浏览器没有弹出“是否打开”？**
A：用 5.2 的备用办法：复制导入码，回到软件按 `Ctrl + V`。

**Q：显示导入码已过期 / 已使用？**
A：导入码 10 分钟内有效、只能用一次。回站点重新点「一键导入」。

**Q：检查连接显示余额不足？**
A：到站点钱包充值，或在令牌页调高这个 Key 的额度。

**Q：Key 安全吗？**
A：Key 用系统加密保存在本机，不会上传；也不要把 Key 发给任何人，包括 AI 助手。

**Q：费用怎么算？**
A：按站点的实际扣费。软件的 **设置 → 账本与上限** 可以给单个对话、每天、每月设上限，到了自动停止。

**Q：站点的问题（充值、模型、价格）找谁？**
A：联系你所用站点的客服。软件本身的问题，加 QQ 群 1131210592。

## 9. 给站点运营者：站点需要支持什么

如果你运营一个 API 站点，希望用户可以用「智能 Key + 一键导入」接入万能创作终端，站点需要：

1. **OpenAI 兼容接口**：提供标准的 `/v1/models`、`/v1/chat/completions` 等接口，以及你的站点支持的图片、视频生成接口。
2. **智能路由（可选但推荐）**：提供一种 Key，让它在调用“智能”模型时自动选择可用线路。没有智能路由也能接入，用户按手动方式配置即可。
3. **一键导入**：在令牌页为每个 Key 提供「一键导入」按钮，生成一份 **短时有效（建议 10 分钟）、只能使用一次** 的导入数据，包含接口地址、Key 以及文本 / 图片 / 视频 / 编程助手的默认模型，并提供三种交付方式：
   - 唤起软件的链接（浏览器询问后打开软件）；
   - 可复制的导入码；
   - 可下载的导入文件。
4. **不要在导入数据之外传输或保存用户 Key**；软件在用户确认之前不会改动任何设置。

一键导入的数据格式和接入细节，请在 QQ 群 1131210592 联系我们获取。

站点运营者还可以使用官方提供的 **静态下载页**：修改一个 `config.json` 就能显示你的站点名称、注册入口和联系方式，放在任何静态托管上。说明见仓库中的 `site/PARTNER_README.md`。
