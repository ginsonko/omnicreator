# 万能创作终端 · 智能路由站点快速上手（1 页）

> 适合：你的 API 站点支持 **智能 Key** 和 **一键导入**。详细说明见 [第三方智能路由站点接入手册](第三方智能路由站点接入手册.md)。
> 站点不支持一键导入？看 [通用版快速上手](通用版快速上手.md)。

## 第 1 步：下载安装

1. 从官网下载区或 <https://github.com/ginsonko/omnicreator/releases> 下载：
   - Windows：`…-Setup.exe`（安装版，推荐）
   - Mac Apple 芯片：`…-mac-arm64.dmg`；Mac Intel：`…-mac-x64.dmg`（需要 macOS 13 或更高）
2. Windows 被拦住时点「更多信息」→「仍要运行」。
3. Mac：把「OmniCreator」拖进「应用程序」。第一次打开：macOS 13/14 **右键 →「打开」→「打开」**；macOS 15 双击一次点「完成」，再到 **系统设置 → 隐私与安全性** 点「仍要打开」。提示“已损坏”就在「终端」运行：
   ```
   sudo xattr -dr com.apple.quarantine /Applications/OmniCreator.app
   ```
4. 打开软件，**保持开着**。

## 第 2 步：注册并充值

在你的站点注册、登录，到「钱包 / 充值」充值（在线支付或兑换码）。

## 第 3 步：创建智能 Key

「令牌」页 →「添加令牌」→ 类型选 **智能** → 设个额度上限 → 提交。

## 第 4 步：一键导入

1. 在这个 Key 那一行点 **「一键导入」** → 选 **「万能创作终端」** → **「导入到软件」**。
2. 浏览器问是否打开，选 **「打开」**。
3. 软件弹出确认窗口，核对后点 **「导入」**。

没反应？在站点弹窗点「复制导入码」，回到软件按 **Ctrl + V**（Mac：⌘ + V）。导入码 10 分钟内有效、只能用一次。

## 第 5 步：确认并开始

1. **配置 → 连接** 里出现带「一键导入」「智能路由」标签的卡片，点 **「检查连接」** 显示“连接正常”。
2. 回到首页直接说：
   - `帮我做一张新品咖啡海报，暖色调，留出标题位置`
   - `把这张图做成 5 秒视频，镜头缓慢推近`
   - `给新品焦糖拿铁写 3 条小红书文案`

成果自动保存在右侧「作品」。导错了可在 **配置 → 连接** 底部「撤销上次导入」。

## 其他

- `F1` 帮助 · `F2` 换界面 · 花费上限在 **配置 → 账本与上限**。
- 有新版时左下角提示「立即更新 / 稍后 / 跳过此版本」，**从不强制**，更新保留全部设置和对话。
- 卸载：**配置 → 关于 →「卸载本软件」**（默认保留数据）；免安装版先「清除软件数据」再删 exe。
